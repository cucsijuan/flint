# Daily notes and templates

This vault keeps daily notes in `Journal/` using the `Templates/Daily` template (Settings → Daily notes).

- Open today's note with the calendar button in the left sidebar.
- In a daily note, the arrows next to its title (or Ctrl+Alt+← / →) go to the previous or next one: try [[2026-01-05]].
- In any note, **Insert template** (Ctrl+Shift+T or right-click) adds a note from `Templates/`, filling in `{{title}}`, `{{date}}`, `{{time}}` and formats like `{{date:dddd, D MMMM}}`.
