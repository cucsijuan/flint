# Editing

Flint edits plain Markdown files. **Live preview** hides the syntax except where the cursor is; move the cursor into this **bold** text or a [[Start here|link]] to see it.

## Modes

- Live preview and source mode: Settings → Editing mode.
- Reading view: Ctrl+E, or the book icon in the note header.

## Formatting

Select a word and try Ctrl+B, Ctrl+I, Ctrl+K (internal link), or right-click for **Bold**, _Italic_, ~~Strikethrough~~, `Code` and **Insert link**. The right-click menu also offers spelling suggestions: tpyo.
