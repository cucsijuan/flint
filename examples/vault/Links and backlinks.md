# Links and backlinks

## Wikilinks

- A note: [[Tags]]
- A heading in a note: [[Rich content#Tables]]
- With a different text: [[Properties|the properties demo]]
- Through an alias: [[Tour]] opens [[Start here]]
- A note that doesn't exist yet: [[Not written yet]] (click to create it)

Type `[[` to autocomplete notes, and `[[Tags#` to pick a heading.

## Markdown links

- Same folder: [Editing](Editing.md)
- A section: [Callouts](Rich%20content.md#Callouts)
- Relative path: [the roadmap](./Projects/Roadmap.md)
- A website: [Flint on GitHub](https://github.com/cucsijuan/flint)

## Backlinks and renaming

Open **Tags** and look at its backlinks panel: this note is listed there. Rename **Tags** in the file tree (double-click it) and every link above updates, Markdown links included.
