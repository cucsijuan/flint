# Plugins

Plugins live in `.flint/plugins/<name>/`. To try the examples in the Flint repository, copy `examples/word-count` and `examples/counter` into this vault's `.flint/plugins/` folder, then enable them in Settings → Plugins.

With **Counter** enabled, this block becomes a button that counts clicks in the note itself:

```counter
0
```

**Word count** adds a sidebar tab and an **Insert current date** command (Ctrl+Shift+D).
