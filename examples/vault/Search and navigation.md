# Search and navigation

- **Search** (Ctrl+Shift+F): try `callout`, `"live preview"`, `tag:#project`, `path:Projects`, `-draft`, `task OR tag` or `/gr[ae]y/`.
- **Quick switcher** (Ctrl+O): jump to a note by name or alias; Shift+Enter creates one.
- **Command palette** (Ctrl+P): every action, with its shortcut.
- **Tabs**: Ctrl+click or middle-click a link to open it in a new tab. Ctrl+T, Ctrl+W, Ctrl+Tab.
- **Panes**: right-click a tab to split it, or drag a tab to a pane's edge.
- **History**: Alt+← and Alt+→ in each tab.
- **Files**: drag notes and folders in the file tree to move them; links follow.
