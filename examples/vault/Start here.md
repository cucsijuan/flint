# Start here

This vault shows every Flint feature. Open it with **Open another vault**. Work on a copy if you want to keep this folder unchanged.

Each note below covers one area. Follow the links, then open the **graph** (Ctrl+G) to see how they connect.

1. [[Editing]]: live preview, source mode and the reading view (Ctrl+E)
2. [[Links and backlinks]]: wikilinks, aliases, headings and Markdown links
3. [[Tags]]: inline and frontmatter tags
4. [[Rich content]]: images, tables, embeds, callouts, tasks and code
5. [[Properties]]: frontmatter as an editable form
6. [[Daily notes and templates]]
7. [[Search and navigation]]: search, quick switcher, command palette, tabs and panes
8. [[Outline and bookmarks]]
9. [[Plugins]]

> [!tip] Appearance
> Settings → Appearance changes the theme, accent color and fonts. Three CSS snippets ship in `.flint/snippets`: turn them on there.

> [!tip] Right sidebar
> Backlinks, outline, properties, tags and the local graph for the open note live in the right sidebar.
