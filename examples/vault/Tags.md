# Tags

Inline tags like #flint and nested ones like #project/alpha and #project/beta work anywhere outside code.

Frontmatter `tags` count too: this note is tagged `demo` and `reference`.

Click a tag to search for it, or open the tags panel in the right sidebar. Parent tags such as `project` count the notes of their children.

`#not-a-tag` inside code is ignored.
